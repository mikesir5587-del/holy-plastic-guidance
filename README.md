# HolyPlastic Landing Page

Создай с нуля полностью готовый адаптивный одностраничный сайт HolyPlastic на русском языке.

ВНИМАНИЕ: приложенный файл HolyPlastic_master_prompt_RU.md — главный и обязательный источник требований. Сначала прочитай его ЦЕЛИКОМ, затем сразу реализуй сайт, не ограничивайся планом или макетом. Соблюдай все факты, цены, формулировки, ограничения контента, дизайн-систему, структуру прогрева, UX, SEO, accessibility, performance и QA из документа.

Ключевые условия исполнения:
- Реализуй production-quality responsive landing page для мобильных 360/390/430 px, планшета 768 px и desktop 1280/1440 px.
- Интерфейс и весь пользовательский текст — на русском.
- HolyPlastic — сервис консультационного и организационного сопровождения оформления собственной дебетовой Visa в банке Великобритании; не банк, не эмитент и не посредник по оплате чужой картой.
- Сохрани цены Virtual 12 000 ₽ и Virtual + Physical 15 000 ₽, только подтверждённые сведения и честные оговорки из ТЗ.
- Telegram URL не предоставлен: не создавай фальшивую/пустую кнопку. Все основные CTA должны вести на mailto:holyplastic@yandex.com с осмысленной темой письма; контакты должны копироваться там, где это предусмотрено ТЗ.
- Никакого backend, авторизации, базы данных и сбора паспортных данных на сайте.
- Визуально: продуманный современный chrome/glass editorial fintech, светлый и спокойный, с сильной типографикой и композиционной глубиной; не шаблонный bento, не чёрно-неоновая криптобиржа, без ложных логотипов банков/партнёров.
- Все интерактивы должны работать: навигация по якорям, мобильное меню, FAQ, CTA, копирование email, состояния hover/focus.
- После реализации сам проверь отсутствие горизонтального скролла, читаемость, кликабельность, контраст, мобильное меню, ссылки и консольные ошибки. Исправь найденное до завершения.
- Назови проект HolyPlastic.

Не останавливайся ради уточнений: если в ТЗ нет подтверждённого факта, используй честную нейтральную формулировку или не обещай его.
